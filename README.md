https://kaskadiia.github.io/EvergreenTab/

## Features

- Functioning search bar with five engines
- Five shortcuts
- Time and date
- A background that changes every hour through Pexels API

## Localhost

- Clone the repo
- Run `npm install` to install dependencies
- Sign up for Pexels and get an API key
- Create a `.env` file at the root directory
  - Set `VITE_PEXELS_API_KEY` to your API key
- Start the dev server `npm run dev` and open through the link
